# 05 — Regular Expressions

Practical guide to Python's `re` module: from basic pattern syntax through real-world log parsing, data validation, text transformation, and performance optimisation.

## Notebooks

| # | Notebook | Topics |
|---|----------|--------|
| 01 | [Working with Regular Expressions in Python](01-working-with-regular-expressions-in-python/01-working-with-regular-expressions-in-python.ipynb) | Regex syntax, special characters, anchors, character classes, quantifiers, groups, `re` functions, flags, raw strings |
| 02 | [Searching and Matching Patterns in Files](02-searching-and-matching-patterns-in-files/02-searching-and-matching-patterns-in-files.ipynb) | `search` vs `match`, line-by-line file reading, `findall`, named groups, compiled patterns, scanning multiple files |
| 03 | [Validating User Input and Data](03-validating-user-input-and-data/03-validating-user-input-and-data.ipynb) | `fullmatch` for usernames, numeric and email validation, code/SQL injection detection and sanitization |
| 04 | [Parsing Log Files](04-parsing-log-files/04-parsing-log-files.ipynb) | IP extraction, log-level filtering, error-code extraction, structured parsing, live stream filtering |
| 05 | [Replacing, Transforming and Cleaning Data](05-replacing-transforming-and-cleaning-data/05-replacing-transforming-and-cleaning-data.ipynb) | `sub` for phone standardisation, spell correction, lookahead/lookbehind, date/price reformatting, CSV cleaning, Unicode, data redaction |
| 06 | [Optimize Regex Patterns](06-optimize-regex-patterns/06-optimize-regex-patterns.ipynb) | Greedy vs non-greedy, non-capturing groups, `re.compile`, `re.DEBUG`, `re.VERBOSE`, catastrophic backtracking |

- Jupyter Notebook or JupyterLab
