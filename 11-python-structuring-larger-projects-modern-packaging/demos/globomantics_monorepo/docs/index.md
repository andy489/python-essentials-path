# Globomantics Platform

Welcome to the Globomantics platform documentation.

This site describes the core services in our logistics and billing platform:

- Shared utilities (`globomantics_shared`)
- Customer and shipment data (`globomantics_data`)
- Analytics and tiering (`globomantics_analytics`)
- Billing and invoicing (`globomantics_billing`)
- Plug-in extensions (`globomantics_plugins`)
- Command-line interface (`globomantics_cli`)

Use this documentation as the single source of truth for how the platform is structured and how teams should integrate with it.
