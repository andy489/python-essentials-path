Phonebook
=========
Given a list of names and phone numbers, make a Phonebook. Determine if it is consistent:

* No duplicates
* No number is a prefix of another

Enterprise features
-------------------
* Populate a phonebook from a file.
* Only authenticated users may look up a number in the phonebook.
* Reject additions to the phonebook that would make it inconsistent.
* Report which numbers most frequently prevent new numbers from being added.
